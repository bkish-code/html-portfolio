# html-portfolio
This repository is for the Introduction to Website class.
We will be hosting our websites on GitHub.
Required: index.html file. This will be your homepage.
Optional Files but required for the class:
- style.css (Adds visual styling such as colors, fonts, and layout).
- script.js (Adds interactivity such as buttons, animations, etc.).
- assets/ folder (Stores images, videos, or other media).
